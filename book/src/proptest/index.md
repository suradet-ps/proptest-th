# เครต `proptest`

เครต `proptest` บรรจุฟังก์ชันการทำงานหลักส่วนใหญ่ของ Proptest ครอบคลุมทั้งกลยุทธ์การสร้างข้อมูล (strategies) เกือบทั้งหมด และตัวเฟรมเวิร์กสำหรับการทดสอบ

เนื้อหาในส่วนนี้เน้นการแนะนำการใช้งาน ตั้งแต่บทเรียนฝึกปฏิบัติ (tutorials) ไปจนถึงแนวทางการใช้งานทั่วไป โดยจะ _ไม่มี_ เอกสารอ้างอิง API (API reference) หากต้องการดูเอกสารอ้างอิง API อย่างละเอียด โปรดดูที่ [เอกสาร rustdoc](https://docs.rs/proptest/latest/proptest/)
