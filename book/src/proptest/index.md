# เครต `proptest`

เครต `proptest` มีฟังก์ชันการทำงานส่วนใหญ่ของ Proptest เอาไว้ให้ ไม่ว่าจะเป็นกลยุทธ์เกือบทั้งหมดและตัวเฟรมเวิร์กการทดสอบเอง

ส่วนนี้ของหนังสือเน้นเนื้อหาเบื้องต้น เช่น บทช่วยสอน และคำแนะนำการใช้งานทั่วไป โดยจะ _ไม่_ มีเอกสารอ้างอิงรวมอยู่ด้วย หากต้องการเอกสารอ้างอิง โปรดดูที่ [เอกสาร rustdoc](https://docs.rs/proptest/latest/proptest/)
