# ทำความรู้จัก Proptest จากพื้นฐานขึ้นไป

บทเรียนนี้จะพาคุณไปรู้จักกับ Proptest จากรากฐานล่างสุดขึ้นไป (Bottom-Up Approach) โดยเริ่มจากชิ้นส่วนประกอบพื้นฐาน เพื่อช่วยให้เห็นภาพรวมของกลไกทั้งหมดอย่างกระจ่างแจ้ง โดยเฉพาะอย่างยิ่ง เราจะเริ่มศึกษาโดยไม่ใช้มาโคร (macros) ใดๆ เพื่อให้คุณเข้าใจได้ว่าเมื่อใช้งานจริง มาโครเหล่านั้นถูกแปลง (expand) ออกมาเป็นโค้ดอย่างไรแทนที่จะมองว่าเป็นเรื่องลึกลับ แต่ด้วยเหตุนี้ เนื้อหาในส่วนแรกจึง _ไม่ใช่_ รูปแบบการเขียนโค้ด Proptest ตามปกติทั่วไป หากคุณไม่คุ้นเคยกับการเรียนรู้แบบ bottom-up คุณอาจเลือกกวาดตาอ่านหัวข้อแรกๆ เหล่านี้แบบคร่าวๆ ก่อนได้

ข้อควรทราบอีกประการคือ ตัวอย่างโค้ดในบทนี้เน้นแสดงการใช้งานเครื่องมือของ Proptest เองเป็นหลัก จึงทำให้เนื้อหาในฟังก์ชันทดสอบดูเรียบง่ายมาก (trivial) แต่ในการเขียนโค้ดจริง คุณย่อมจะต้องใส่การตรวจสอบเงื่อนไข (assertions) และตรรกะการทดสอบต่างๆ ไว้อย่างครบถ้วน
