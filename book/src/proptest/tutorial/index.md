# ทำความรู้จัก Proptest จากพื้นฐานขึ้นไป

บทช่วยสอนนี้จะแนะนำ proptest จากพื้นฐานขึ้นไป โดยเริ่มจากส่วนประกอบพื้นฐานที่สุด เพื่อให้เห็นภาพรวมของโมเดลทั้งหมดได้ชัดเจนขึ้น โดยเฉพาะอย่างยิ่ง เราจะเริ่มต้นโดยไม่ใช้มาโครก่อน เพื่อให้เข้าใจได้ในภายหลังว่ามาโครแต่ละตัวขยายออกมาเป็นอะไร แทนที่จะมองว่าเป็นเวทมนตร์ แต่ผลก็คือส่วนแรกของบทช่วยสอนนี้ _ไม่_ ใช่ตัวแทนของการใช้งาน proptest ตามปกติ หากคุณไม่ถนัดการเรียนรู้จากพื้นฐานขึ้นไป อาจลองอ่านผ่านๆ หัวข้อแรกๆ ก็ได้

นอกจากนี้ ตัวอย่างในบทนี้เน้นที่การใช้งานตัว proptest เอง จึงมักมีเนื้อหาการทดสอบที่เรียบง่ายมาก ในโค้ดจริง คุณก็คงมีการแอสเซอร์ชันและอื่นๆ อยู่ในเนื้อหาการทดสอบอย่างแน่นอน
