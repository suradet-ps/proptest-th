# การตั้งค่าจำนวนกรณีทดสอบที่ต้องการ

จำนวนรอบเริ่มต้นของกรณีทดสอบที่ต้องรันผ่านสำเร็จเพื่อให้เทสต์ทั้งหมดถือว่าผ่าน ปัจจุบันถูกกำหนดไว้ที่ 256 ครั้ง หากคุณต้องการปรับจำนวนรอบให้มากขึ้นหรือน้อยลง สามารถทำได้หลายวิธี:

วิธีแรกคือ การกำหนดค่าตัวแปรสภาพแวดล้อม `PROPTEST_CASES` ให้เป็นตัวเลขจำนวนเต็มบวก (`u32`) โดยค่านี้จะกลายเป็นค่าเริ่มต้นใหม่สำหรับการทดสอบทุกตัว (วิธีนี้ใช้งานได้เมื่อเปิดฟีเจอร์ `std` ของ Proptest ซึ่งเปิดใช้งานเป็นค่าเริ่มต้นอยู่แล้ว)

อีกวิธีหนึ่งคือ การระบุแอตทริบิวต์ `#![proptest_config(expr)]` ไว้ด้านบนสุดภายในบล็อก `proptest!` โดยที่ `expr` คือนิพจน์ที่ให้ค่าเป็น `ProptestConfig` (หรือ `Config`) หากต้องการเปลี่ยนเฉพาะจำนวนรอบการทดสอบ สามารถเขียนได้ง่ายๆ ดังนี้:

```rust
# extern crate proptest;
use proptest::prelude::*;

fn add(a: i32, b: i32) -> i32 { a + b }

proptest! {
    // The next line modifies the number of tests.
    #![proptest_config(ProptestConfig::with_cases(1000))]
    #[test]
    # fn dummy(a in 0..1) {} // Doctests don't build `#[test]` functions, so we need this
    fn test_add(a in 0..1000i32, b in 0..1000i32) {
        let sum = add(a, b);
        assert!(sum >= a);
        assert!(sum >= b);
    }
}
# fn main() {
#     test_add();
# }
```

นอกจากนี้ คุณยังสามารถใช้กลไก `proptest_config` เดียวกันนี้เพื่อปรับแต่งการตั้งค่าอื่นๆ อย่างละเอียดผ่านโครงสร้าง `Config` ได้อีกด้วย สามารถดูรายละเอียดเพิ่มเติมได้ที่เอกสารอ้างอิงของ `ProptestConfig`
