# บทนำ

Proptest เป็นเฟรมเวิร์กสำหรับการทดสอบพร็อพเพอร์ตี (property testing) หรือที่รู้จักกันในชื่อตระกูล QuickCheck โดยได้แรงบันดาลใจมาจากเฟรมเวิร์ก [Hypothesis](https://hypothesis.works/) สำหรับภาษา Python โปรแกรมนี้ช่วยให้คุณทดสอบว่าพร็อพเพอร์ตีบางอย่างของโค้ดเป็นจริงกับอินพุตใดๆ หรือไม่ และเมื่อพบว่ามีกรณีที่ล้มเหลว ก็จะค้นหากกรณีทดสอบที่เล็กที่สุดที่ทำให้เกิดปัญหาได้โดยอัตโนมัติ ต่างจาก QuickCheck ตรงที่การสร้างค่าและการชริงก์ถูกนิยามในระดับค่าทีละค่า ไม่ใช่ระดับชนิดข้อมูล จึงยืดหยุ่นกว่าและประกอบกลยุทธ์เข้าด้วยกันได้ง่ายกว่า

## สถานะของครีตนี้

ครีตนี้เกือบจะมีฟีเจอร์ครบสมบูรณ์แล้ว และไม่ได้มีการเปลี่ยนแปลงเชิงสถาปัตยกรรมที่สำคัญมาระยะหนึ่งแล้ว ปัจจุบันอยู่ในช่วงการบำรุงรักษาแบบไม่เชิงรุกเป็นหลัก

ดู [changelog](https://github.com/proptest-rs/proptest/blob/main/proptest/CHANGELOG.md) เพื่อดูรายการการเปลี่ยนแปลงเชิงประวัติศาสตร์ที่สำคัญทั้งหมด รวมถึงการเปลี่ยนแปลงที่ทำให้โค้ดเดิมใช้ไม่ได้ด้วย

## การทดสอบพร็อพเพอร์ตีคืออะไร?

_การทดสอบพร็อพเพอร์ตี_ คือวิธีการทดสอบโค้ดโดยตรวจสอบว่าพร็อพเพอร์ตีบางอย่างของผลลัพธ์หรือพฤติกรรมของโค้ดเป็นจริงกับอินพุตทุกค่า อินพุตเหล่านี้จะถูกสร้างขึ้นโดยอัตโนมัติ และที่สำคัญที่สุด เมื่อพบอินพุตที่ทำให้เกิดความล้มเหลว ระบบจะย่ออินพุตนั้นลงเป็นกรณีทดสอบที่ _เล็กที่สุด_ ให้โดยอัตโนมัติ

การทดสอบพร็อพเพอร์ตีเหมาะที่สุดสำหรับใช้เสริมกับการทดสอบระดับยูนิตแบบดั้งเดิม (กล่าวคือ การใช้ค่าอินพุตเฉพาะที่เลือกไว้ด้วยมือ) การทดสอบแบบดั้งเดิมสามารถตรวจสอบกรณีขอบเขตที่รู้อยู่แล้ว อินพุตแบบง่ายๆ และอินพุตที่เคยเป็นที่รู้กันในอดีตว่าทำให้เกิดบั๊ก ส่วนการทดสอบพร็อพเพอร์ตีจะค้นหาอินพุตที่ซับซ้อนกว่าซึ่งก่อให้เกิดปัญหา
