# ครีต `proptest-derive`

ครีต `proptest-derive` มีมาโครเชิงกระบวนการ (procedural macro) ชื่อ `#[derive(Arbitrary)]` ซึ่งใช้สร้างการนำเทรต `Arbitrary` ไปใช้แบบง่ายๆ ให้กับชนิดข้อมูลที่ผู้ใช้กำหนดเองได้โดยอัตโนมัติ ทำให้ชนิดข้อมูลเหล่านั้นใช้งานร่วมกับ `any()` และฝังอยู่ในชนิดข้อมูลอื่นที่ `#[derive(Arbitrary)]` ได้อย่างราบรื่น

แนะนำให้มีความเข้าใจพื้นฐานเกี่ยวกับ[ครีต `proptest`](/proptest/index.md) มาก่อนที่จะอ่านเอกสารส่วนนี้

**ปัจจุบันครีตนี้ยังอยู่ในขั้นทดลองอยู่พอสมควร** โปรดคาดว่าจะเจอความไม่เรียบร้อย โดยเฉพาะในเอกสารประกอบ อีกทั้งยังมีแนวโน้มที่จะออกเวอร์ชันที่มีการเปลี่ยนแปลงที่ทำให้โค้ดเดิมใช้ไม่ได้บ่อยกว่าครีต `proptest` หลักอีกด้วย
