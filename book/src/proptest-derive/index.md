# เครต `proptest-derive`

เครต `proptest-derive` มีโพรซีเดอรัลมาโคร (Procedural Macro) ชื่อ `#[derive(Arbitrary)]` ซึ่งช่วยสร้างโค้ดอิมพลีเมนต์เทรต `Arbitrary` ให้กับชนิดข้อมูลที่ผู้ใช้กำหนดขึ้นเองโดยอัตโนมัติ ทำให้คุณสามารถนำชนิดข้อมูลเหล่านั้นไปใช้งานร่วมกับฟังก์ชัน `any()` หรือนำไปใช้เป็นฟิลด์ซ้อนในชนิดข้อมูลอื่นที่ใส่ `#[derive(Arbitrary)]` ได้อย่างราบรื่นโดยไม่ต้องเขียนโค้ดเอง

ขอแนะนำให้ทำความเข้าใจการทำงานพื้นฐานของ [เครต `proptest`](../proptest/index.md) มาก่อนที่จะเริ่มศึกษาเนื้อหาในส่วนนี้

**เครตนี้ยังอยู่ในขั้นทดลอง (experimental)** จึงอาจยังมีความไม่สมบูรณ์อยู่บ้าง โดยเฉพาะในส่วนของเอกสารประกอบ นอกจากนี้ เครตนี้ยังมีโอกาสที่จะมีเวอร์ชันใหม่ที่มีการเปลี่ยนแปลงที่ส่งผลกระทบต่อโค้ดเดิม (breaking changes) มากกว่าเครตหลัก `proptest`
